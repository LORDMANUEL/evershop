# Auto_Fitment

Esqueleto inicial para la extensión de compatibilidad de autopartes. Aquí se añadirán:

- Migraciones para `fitment_vehicle`, `fitment_link` y `cross_reference`.
- Schemas y resolvers GraphQL que expongan los datos de compatibilidad desde EverShop.
- Interfaces de administración para gestionar fitment, referencias cruzadas e importaciones masivas.

> _Estado actual_: únicamente incluye un placeholder para facilitar el registro de la extensión dentro del monorepo.

# Auto_VIN

Extensión destinada a consumir la API pública de NHTSA vPIC para decodificar VIN y normalizar los datos de vehículo.

Pendiente de implementación:

- Endpoint proxy con control de rate limiting y caché básica.
- Normalización de campos (Make, Model, Year, Trim, Engine).
- Integración con el widget “Garage” en el storefront para persistir vehículos.

> _Estado actual_: estructura base para comenzar el desarrollo.

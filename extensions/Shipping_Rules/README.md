# Shipping_Rules

Extensión destinada a centralizar las reglas de logística para la tienda de autopartes.

Futuras capacidades:

- Tarifas por zona y modalidad (envío a domicilio, retiro en tienda).
- Cálculo por peso, dimensiones y sobrecargos (ej. core charge, sobredimensionados).
- Soporte para múltiples almacenes con tiempos estimados de entrega.

> _Estado actual_: únicamente provee un esqueleto para comenzar el desarrollo logístico.
